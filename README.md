# LelekaTalk

Вебмесенджер для спілкування, спільнот і творчості. Поточна версія — локальний MVP 0.2: зашифровані особисті та групові текстові чати, канали, стрічка, календар і трекер звичок.

## Запуск

Потрібен Node.js 22 або новіший.

```sh
cd phase-one
npm ci
npm start
```

Відкрий http://127.0.0.1:3000. Після реєстрації збережи код відновлення приватних даних. Для двох акаунтів використовуй окремі профілі браузера або звичайне та приватне вікна.

```sh

```

14 серверних тестів. Наскрізні сценарії перевірено у Chromium на комп’ютерному й мобільному екранах.

## Стан продукту

Це локальна збірка для тестування. Android APK, платежі, дзвінки, ефіри, студія та ШІ ще не реалізовані. Для публічного релізу потрібні виробнича інфраструктура й перевірка безпеки; поточна криптографічна інтеграція не має незалежного аудиту або forward secrecy.

Локальні акаунти, шифровані ключі й дані користувачів у `phase-one/data/`, залежності та секрети `.env` виключені з Git.
