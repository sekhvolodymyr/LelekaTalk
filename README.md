# LelekaTalk

Вебмесенджер для спілкування, спільнот і творчості. Поточна версія — MVP 0.2: зашифровані особисті та групові текстові чати, канали, стрічка, календар і трекер звичок.

Онлайн: [lelekatalk.vercel.app](https://lelekatalk.vercel.app). Сервер працює на Vercel, постійні дані зберігаються у приватній схемі Supabase Postgres.

У чаті доступні смайли з категоріями та пошуком. Для push натисни «Увімкнути сповіщення» й надай дозвіл браузеру. Сповіщення не показує текст зашифрованої розмови. Вимкнення доступне тією самою кнопкою; вихід відписує поточний браузер.

В особистому чаті зі взаємно прийнятим контактом натисни «Аудіодзвінок». Доступні прийняття/відхилення, вимкнення мікрофона й завершення. Аудіо передається через WebRTC і не записується сервером. Поки TURN не підключено, деякі мобільні та закриті мережі можуть не встановити з'єднання.

## Запуск

Потрібен Node.js 22 або новіший.

```sh
cd phase-one
npm ci
npm start
```

Відкрий http://127.0.0.1:3000. Після реєстрації збережи код відновлення приватних даних. Для двох акаунтів використовуй окремі профілі браузера або звичайне та приватне вікна.

## Перевірка

```sh
cd phase-one
npm test
```

14 серверних тестів. Команда `npm test` з кореня також запускає 4 тести хмарного адаптера, 5 тестів push, регресійний тест криптографічного часу та 4 тести дзвінків — разом 28. Наскрізні сценарії перевірено у браузері на комп’ютерному й мобільному екранах.

## Стан продукту

Це MVP для тестування, доступний онлайн і локально. Android APK, платежі, відео/групові дзвінки, ефіри, студія та ШІ ще не реалізовані. Для повноцінного публічного релізу потрібні подальші перевірки безпеки та навантаження; поточна криптографічна інтеграція не має незалежного аудиту або forward secrecy.

Локальні акаунти, шифровані ключі й дані користувачів у `phase-one/data/`, залежності та секрети `.env` виключені з Git.
