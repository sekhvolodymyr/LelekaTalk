# LelekaTalk — локальний MVP 0.2

На основі ../LelekaTalk-PRD-2026-10-08.md. Обраний обсяг: месенджер, канали/стрічка, календар і трекер звичок. Українська й англійська мови, світла/темна теми та наданий логотип.

## Запуск

Потрібен Node.js 22+. У PowerShell:

```powershell
Set-Location 'C:\Users\volod\Documents\LelekaTalk\phase-one'
npm ci
npm start
```

Відкрий http://127.0.0.1:3000. Пароль: від 12 символів; username: 3–24 латинські літери, цифри або _. Під час першого входу збережи код відновлення: він відрізняється від пароля акаунта і потрібен на новому пристрої або після виходу.

Для перевірки спілкування створи два акаунти в окремих профілях браузера або звичайному й приватному вікнах. Знайди другого користувача через «Новий чат» за username, надішли запит і прийми його з другого акаунта. Вкладки одного профілю браузера використовують спільну сесію.

Сервер слухає тільки 127.0.0.1. Інший порт: змінна PORT. Доступ з телефона через мережу й публічний хостинг ще не налаштовані.

## Реалізовано

- Реєстрація, вхід, вихід; паролі scrypt, сесії HttpOnly/SameSite-cookie. Два профільні імені й настройка видимості зв’язку.
- Особисті текстові чати, приватні групи до 25 учасників, пошук, запити й згода кожного запрошеного, блокування, вихід з групи, історія з пагінацією. Оновлення раз на 2 секунди.
- Повідомлення шифруються й підписуються у браузері через OpenPGP.js. Коди безпеки можна порівняти через інший канал.
- Випадковий код відновлення шифрує приватний ключ перед передачею на сервер; сам код не надсилається. Пристрій зберігає ключ у IndexedDB, загорнутий AES-GCM з неекспортованим ключем Web Crypto. Вихід видаляє цю локальну копію.
- Канали креаторів, публічні текстові дописи, підписки, вподобання, коментарі, видалення власником. Особистий username каналу видимий лише за ввімкненої настройки зв’язку профілів.
- Стрічки «Підписки» й «Для вас». Ранжування другої: підписки, теми підписок/вподобань і свіжість; приватні повідомлення не використовуються.
- Календар по днях: назва, час, виконання, видалення. Звички: назва, позначки останніх 7 днів, серія, видалення. Назви зашифровані для власника; дати й виконання — службові дані.
- Скарги тільки з власноруч написаним описом, без передачі повідомлень. Панелі модератора ще немає.
- Manifest/service worker для веб/PWA-оболонки; API та приватні дані service worker не кешує.

## Перевірки

Запусти npm test. 14 серверних тестів перевіряють акаунти, згоду на чат, шифротекст і підписи, сторонній доступ, блокування, групову історію, права власника каналу, стрічку та приватність планів/звичок. Тестові дані видаляються після перевірки. Браузерні результати — у IMPLEMENTATION.md.

## Безпека й збереження

OpenPGP з постійними ключами не має forward secrecy, автоматичної ротації або властивостей Signal. Перший ключ запам’ятовується за TOFU; особу підтверджує порівняння кодів через інший канал. Незалежного аудиту інтеграції ще не було. Сервер, що підмінить JavaScript, може атакувати вебклієнт.

Сервер бачить email, імена, публічний контент, назви груп, склад чатів, відправників, час/розміри повідомлень, дати й виконання планів. Повідомлення та назви планів/звичок зберігаються як шифротекст; приватний ключ — зашифрований кодом. Сховище браузера не захищає від шкідливого коду того самого origin або компрометації пристрою.

Збережи код до закриття банера. Без нього та пристрою з ключами приватні дані неможливо відновити. Пароль акаунта його не замінює. Нові учасники груп отримують тільки повідомлення після прийняття запрошення. Передача старої історії, повторне запрошення колишніх учасників і відкликання пристроїв не підтримуються.

Серверні дані — data/accounts.json (виключено з Git). Файлове сховище одного локального процесу без резервування та виробничого масштабування. Не публікуй цей файл. Для резервної копії зупини сервер і збережи файл; коди відновлення тримай окремо.

## Межі збірки

Немає підтвердження email, скидання пароля, 2FA, вкладень, редагування повідомлень, push, дзвінків, ефірів, відео/історій, платежів, Premium, студії чи ШІ. Власник групи не може її залишити. Календар без повторних подій/нагадувань. Вік 16+ підтверджує сам користувач.

APK ще не створено. Мобільний вебінтерфейс перевіряється, але встановлення PWA на фізичному Android, офлайн і сповіщення ще не підтверджені. Для спільного доступу та Android потрібні доступний через HTTPS сервер, виробнича база/сесії й перевірка безпеки. Це функціональний локальний MVP, не готовий публічний реліз.
