# Стан реалізації LelekaTalk MVP

Дата: 9 жовтня 2026. Версія 0.2. Обраний обсяг: месенджер, канали/стрічка, календар і звички. Повний PRD збережено без зміни обсягу майбутнього продукту.

| Модуль | Реалізація | Межі |
|---|---|---|
| Акаунти/профілі | Реєстрація, сесії, два імені, зв’язок профілів | Без email-підтвердження, скидання й 2FA |
| Чати | Підписаний зашифрований текст, згода, історія, блокування, смайли, push | Без вкладень |
| Аудіо та відеодзвінки | Особистий WebRTC-дзвінок, прийняття/відхилення, mute, камера off/on, завершення, зашифрована сигналізація | Без TURN, групових дзвінків і запису |
| Групи | Створення, запрошення/згода, вихід, до 25 учасників | Новим учасникам тільки нові повідомлення |
| Ключі | OpenPGP.js, код відновлення, IndexedDB, відбитки | Без forward secrecy/незалежного аудиту |
| Канали/стрічка | Каталог, теми, дописи, підписки, вподобання, коментарі | Текст; просте ранжування |
| Календар | День, час, зашифрована назва, виконання/видалення | Без нагадувань і повторів |
| Звички | Зашифрована назва, позначки, серія, видалення | Останні 7 днів |
| Скарги | Опис без повідомлень | Немає панелі модератора |
| Веб/PWA | Адаптивний інтерфейс, manifest/service worker | Android-встановлення не перевірено |
| APK, платежі, відео/ефіри, студія, ШІ | Не реалізовано | Наступні етапи PRD |

## Перевірки

Сервер: npm test, 14/14 тестів пройшли. Перевірено права доступу, згоду, підписи, відсутність відкритого приватного тексту/коду в JSON, групову історію й приватність планування.

Браузер: Chromium через Playwright. Вбудований браузер недоступний через helper_unknown_error: setup refresh had errors, тому використано наявний Chromium. Наскрізна перевірка пройшла: два акаунти, генерація ключів, згода й обмін повідомленнями, збереження після reload, канали/публікації/підписки/стрічка/вподобання/коментарі, календар і звички, відновлення на третьому пристрої та відхилення неправильного коду, запрошення до групи й недоступність попередньої історії, англійська мова, темна тема, вихід і видалення ключа пристрою. Помилок JavaScript немає. Екрани 1440×900 і 390×844; горизонтального переповнення чату та особистого простору на мобільному немає.

Поточні перевірки хмарної версії описані в ../DEPLOYMENT.md: загалом 30 серверних тестів. Для аудіодзвінків Chrome отримав справжні аудіопакети RTP та DTLS connected в обох напрямках; перевірено мікрофон після згоди, mute, завершення та відхилення.

Фізичний Android, Firefox/Safari, різні мережі/TURN, навантаження та повний офлайн залишаються відкритими. Онлайн-версія працює через HTTPS на Vercel із приватною базою Supabase.

## Архітектура

server.mjs — HTTP, акаунти/сесії, origin, статичні файли.
src/mvp-router.mjs — доступ і збереження модулів MVP.
public/crypto.js — ключі, відновлення, шифрування/підписи у браузері.
public/mvp.js — екрани та polling; public/app.js — оболонка.
tests/server.test.mjs і tests/mvp.test.mjs — автоматичні перевірки.

Node.js, HTML/CSS/JavaScript, OpenPGP.js; зовнішніх платних сервісів немає. JSON для одного локального процесу. Залежність зафіксована package-lock.

Робочий дизайн-референс — design/chat-reference-v1.png. Застосунок використовує оригінальний PNG-логотип. Джерела OpenPGP: https://github.com/openpgpjs/openpgpjs та https://docs.openpgpjs.org/.
